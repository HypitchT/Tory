**Tory**

Tory is a simple quality-of-life Minecraft mod for Quilt (1.19.2) that lets you lock your currently selected hotbar slot by holding the Alt key.
While Alt is held down, scrolling the mouse wheel or pressing the number keys will not change the item you’re holding. This is useful when you want to keep the same tool or item selected while looking around, mining, building, fighting, or doing anything else where accidental item switching is annoying.

**Features**

Hold Left Alt or Right Alt to lock your selected hotbar slot
While locked, mouse scrolling and number keys are ignored
Releases the lock as soon as you let go of Alt
Lightweight and client-side only
No configuration needed — it just works

**How to Use**

Select the hotbar slot you want to keep.
Hold the Alt key.
Look around, mine, fight, or do whatever you need — your selected item will stay locked.
Release Alt when you want to switch items again.

That’s it.

**Installation**

Make sure you have Quilt Loader installed for Minecraft 1.19.2.
Download the latest tory jar from the Releases page or Modrinth.
Place the jar file into your .minecraft/mods folder.
Launch the game.
